# Книга рецептов

Веб-приложение для составления рецептов и поиска блюд.
Стек: **TypeScript + Node.js**, база данных **SQLite** (встроенный модуль `node:sqlite`), интерфейс на HTML/CSS/JS.

## Возможности

- Справочник ингредиентов, разбитых по категориям: мясо, рыба, овощи, специи, травы, молочное, крупы, прочее.
- Справочник операций: нарезка, жарка, варка, тушение, запекание, смешивание, взбивание, маринование, настаивание.
- **Добавление рецептов**: ингредиенты с количеством + упорядоченные шаги (операция над ингредиентами + длительность).
- Автоматический расчёт общего времени и сложности (до 3 операций — простое, 4–6 — среднее, 7+ — сложное).
- Поиск по названию блюда и ингредиентам, фильтры по категории блюда, группам ингредиентов, времени, способу готовки и сложности.
- Добавление нового ингредиента в справочник, удаление своих рецептов.

## Запуск

Нужен **Node.js 22.6 или новее** (проверить: `node -v`). Внешние пакеты для работы не нужны.

```bash
npm start
```

Откройте http://localhost:3000. При первом запуске создаётся файл базы `data/recipes.db` с 9 рецептами и 39 ингредиентами.
Чтобы начать с чистой базы, удалите папку `data`.

Другой порт: `PORT=8080 npm start` (в Windows PowerShell: `$env:PORT=8080; npm start`).

## Структура

```
src/
  types.ts        справочники и типы предметной области
  service.ts      бизнес-логика: время, сложность, поиск, валидация
  repository.ts   доступ к данным (SQL-запросы)
  db.ts           подключение к SQLite, схема таблиц, транзакции
  seed.ts         начальные данные
  server.ts       HTTP-сервер и REST API
  *.test.ts       тесты
public/
  index.html      интерфейс
  app.js          клиентская логика (работает через API)
```

## База данных

| Таблица | Назначение |
|---|---|
| `ingredients` | справочник ингредиентов (`name`, `category`) |
| `recipes` | рецепты (`name`, `dish`, `is_user`, `created_at`) |
| `recipe_ingredients` | состав рецепта: ингредиент + количество |
| `steps` | шаги рецепта: `position`, `operation`, `minutes`, `note` |
| `step_ingredients` | какие ингредиенты участвуют в шаге |

Связи: рецепт 1 → N ингредиентов в составе, рецепт 1 → N шагов, шаг N ↔ M ингредиентов. Удаление рецепта каскадно удаляет его состав и шаги.

## REST API

| Метод | Путь | Описание |
|---|---|---|
| GET | `/api/meta` | категории ингредиентов, операции, категории блюд |
| GET | `/api/ingredients` | список ингредиентов |
| POST | `/api/ingredients` | добавить ингредиент `{ name, category }` |
| GET | `/api/recipes` | поиск рецептов (параметры ниже) |
| GET | `/api/recipes/:id` | один рецепт |
| POST | `/api/recipes` | добавить рецепт |
| DELETE | `/api/recipes/:id` | удалить свой рецепт (встроенные удалить нельзя, ответ 403) |

Параметры поиска: `q`, `dish`, `ingredientCategories` (через запятую), `minMinutes`, `maxMinutes`, `operation`, `difficulty` (`easy,mid,hard`).

Пример: `GET /api/recipes?q=курица&maxMinutes=60&operation=Жарка`

Тело `POST /api/recipes`:

```json
{
  "name": "Сырники",
  "dish": "Завтраки",
  "ingredients": [
    { "ingredientId": 40, "quantity": "400 г" },
    { "ingredientId": 30, "quantity": "1 шт" }
  ],
  "steps": [
    { "operation": "Смешивание", "minutes": 5, "ingredientIds": [40, 30] },
    { "operation": "Жарка", "minutes": 10, "note": "до корочки", "ingredientIds": [40] }
  ]
}
```

Ошибки валидации возвращаются с кодом 400: `{ "errors": ["Укажите название блюда", ...] }`.
